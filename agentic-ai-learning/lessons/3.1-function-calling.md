# 📚 Lesson 3.1 — Function Calling: Giving AI Hands

## 🎯 The "Aha!" Moment

Your chatbot from Lesson 2.3 can **talk**. But it can't **do** anything.

```
👤 User: "What's the weather in Mumbai?"
🤖 Chatbot: "I don't have access to real-time data..." 😞
```

Function calling changes everything:

```
👤 User: "What's the weather in Mumbai?"
🤖 Agent: *internally calls get_weather("Mumbai")* → 32°C, sunny
🤖 Agent: "It's 32°C and sunny in Mumbai! Perfect beach weather. 🏖️" 😎
```

> **Function calling = The AI says "call this function for me" and YOUR code executes it.**

This is THE mechanism that turns a chatbot into an agent.

**Time:** ~30 minutes  
**Prerequisites:** Lesson 2.3 (you can make LLM calls)

## Step 1: Define Your Tool (The "Menu")

You describe your function in JSON — this is the "menu" the AI reads:

```python
tools = [
    {
        "type": "function",
        "function": {
            "name": "get_weather",                          # What to call it
            "description": "Get current weather for a city", # When to use it
            "parameters": {                                  # What inputs it needs
                "type": "object",
                "properties": {
                    "city": {
                        "type": "string",
                        "description": "City name, e.g. 'Mumbai' or 'Delhi'"
                    }
                },
                "required": ["city"]   # city is mandatory
            }
        }
    }
]
```

### Think of it as a restaurant menu:

```
┌─────────────────────────────────────────┐
│  🍽️ TOOL MENU                            │
│                                           │
│  get_weather                              │
│  "Get current weather for a city"        │
│  Requires: city (string)                  │
│                                           │
│  calculate                                │
│  "Do a math calculation"                  │
│  Requires: expression (string)            │
│                                           │
└─────────────────────────────────────────┘
```

The AI reads this menu and decides: "Based on the user's question, I should order `get_weather` with `city='Mumbai'`."

## Step 2: The Actual Python Function

This is YOUR code — the thing that actually runs:

```python
def get_weather(city):
    """Get weather for a city. In real life, this calls a weather API."""
    # Fake data for learning (in production: call OpenWeatherMap, etc.)
    fake_weather = {
        "mumbai": {"temp": 32, "condition": "humid and sunny", "humidity": "78%"},
        "delhi": {"temp": 38, "condition": "hot and dusty", "humidity": "35%"},
        "bangalore": {"temp": 24, "condition": "pleasant and cloudy", "humidity": "60%"},
    }
    
    city_lower = city.lower()
    if city_lower in fake_weather:
        data = fake_weather[city_lower]
        return f"Weather in {city}: {data['temp']}°C, {data['condition']}. Humidity: {data['humidity']}"
    else:
        return f"Sorry, I don't have weather data for '{city}'. Try Mumbai, Delhi, or Bangalore."
```

### 🧪 TRY IT: Test your function directly

```python
# Make sure YOUR function works before involving AI:
print(get_weather("Mumbai"))
print(get_weather("Delhi"))
print(get_weather("London"))  # Should give "sorry" message
```

> 💡 **Pro tip:** Always test your functions independently first. If the function is broken, the agent will be broken.

## Step 3: The Full Flow (Complete Code)

Here's the entire function calling flow in one script:

```python
"""
🔧 Function Calling Demo — Complete Flow
Run: python function_call_demo.py
"""
import json
from dotenv import load_dotenv
from openai import OpenAI

load_dotenv()
client = OpenAI()

# ─── STEP 1: Define the tool schema (the "menu") ────────────
tools = [
    {
        "type": "function",
        "function": {
            "name": "get_weather",
            "description": "Get the current weather for a city in India",
            "parameters": {
                "type": "object",
                "properties": {
                    "city": {
                        "type": "string",
                        "description": "The city name, e.g. 'Mumbai', 'Delhi', 'Bangalore'"
                    }
                },
                "required": ["city"]
            }
        }
    }
]

# ─── STEP 2: The actual function (your code) ────────────────
def get_weather(city):
    """Fake weather API."""
    data = {
        "mumbai": "32°C, humid and sunny ☀️",
        "delhi": "38°C, hot and dusty 🥵",
        "bangalore": "24°C, pleasant and cloudy ⛅",
    }
    return data.get(city.lower(), f"No data for '{city}'. Try Mumbai/Delhi/Bangalore.")

# ─── STEP 3: Send request WITH tools ────────────────────────
user_question = "What's the weather like in Mumbai today?"
print(f"👤 User: {user_question}\n")

messages = [{"role": "user", "content": user_question}]

response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=messages,
    tools=tools,              # ← "Here's your menu"
    tool_choice="auto"        # ← "Decide for yourself"
)

# ─── STEP 4: Check what the AI decided ──────────────────────
message = response.choices[0].message

if message.tool_calls:
    # 🎉 The AI wants to call a function!
    tool_call = message.tool_calls[0]
    
    func_name = tool_call.function.name           # "get_weather"
    func_args = json.loads(tool_call.function.arguments)  # {"city": "Mumbai"}
    call_id = tool_call.id                         # unique ID for tracking
    
    print(f"🤖 AI decided: Call '{func_name}' with args: {func_args}")
    
    # ─── STEP 5: Execute YOUR function ──────────────────────
    result = get_weather(**func_args)  # get_weather(city="Mumbai")
    print(f"🔧 Function result: {result}\n")
    
    # ─── STEP 6: Send result back to AI ─────────────────────
    messages.append(message)  # Add the AI's tool_call message
    messages.append({
        "role": "tool",
        "tool_call_id": call_id,
        "content": result
    })
    
    # ─── STEP 7: AI generates final answer ──────────────────
    final_response = client.chat.completions.create(
        model="gpt-4o-mini",
        messages=messages,
        tools=tools
    )
    
    final_answer = final_response.choices[0].message.content
    print(f"🤖 AI final answer: {final_answer}")

else:
    # AI answered directly (no tool needed)
    print(f"🤖 AI answered directly: {message.content}")
```

### Run it:
```bash
python function_call_demo.py
```

### Expected output:
```
👤 User: What's the weather like in Mumbai today?

🤖 AI decided: Call 'get_weather' with args: {'city': 'Mumbai'}
🔧 Function result: 32°C, humid and sunny ☀️

🤖 AI final answer: The weather in Mumbai today is 32°C with humid and sunny conditions. ☀️ 
Stay hydrated if you're heading out!
```

## 🔍 What Just Happened? (Step by Step)

```
Step 1: You → OpenAI
        "Here's the question + here are available tools"
        
Step 2: OpenAI → You  
        "I want to call get_weather(city='Mumbai')"
        (NOT a text answer — a tool request!)
        
Step 3: You → Your code
        Actually run get_weather("Mumbai") → "32°C, sunny"
        
Step 4: You → OpenAI
        "Here's the tool result: 32°C, sunny"
        
Step 5: OpenAI → You
        "The weather in Mumbai is 32°C and sunny! Stay hydrated!"
        (Final human-friendly answer)
```

**Two API calls for one user question.** That's normal for function calling.

## 🎛️ `tool_choice`: Controlling the AI's Behavior

```python
# Let AI decide (default, most common):
tool_choice="auto"

# Force AI to NOT use tools (answer from knowledge only):
tool_choice="none"

# Force AI to use a SPECIFIC tool:
tool_choice={"type": "function", "function": {"name": "get_weather"}}

# Force AI to use SOME tool (any tool):
tool_choice="required"
```

### When to use each:

| Option | Use When |
|--------|----------|
| `"auto"` | Default. AI decides. 90% of cases. |
| `"none"` | You want pure text, no tool calls |
| `"required"` | You KNOW a tool is needed, force it |
| Specific function | You know exactly which tool to use |

## 🚨 Common Mistakes & Fixes

### Mistake 1: Forgetting to add the assistant message

```python
# ❌ WRONG — jumping straight to tool result:
messages.append({"role": "tool", "tool_call_id": call_id, "content": result})

# ✅ RIGHT — add assistant's tool_call message FIRST:
messages.append(message)  # The assistant message with tool_calls
messages.append({"role": "tool", "tool_call_id": call_id, "content": result})
```

### Mistake 2: Sending non-string content

```python
# ❌ WRONG — sending a dict:
messages.append({"role": "tool", "tool_call_id": call_id, "content": {"temp": 32}})

# ✅ RIGHT — must be a string:
messages.append({"role": "tool", "tool_call_id": call_id, "content": json.dumps({"temp": 32})})
# Or just: content="32°C, sunny"
```

### Mistake 3: Function name mismatch

```python
# Tool schema says: "name": "get_weather"
# But your function is: def getWeather(city):  ← MISMATCH!

# The names must match EXACTLY:
# Schema: "name": "get_weather"  →  Python: def get_weather(city):
```

### Mistake 4: Not handling "no tool call" case

```python
# ❌ WRONG — assumes tool_calls always exists:
tool_call = message.tool_calls[0]  # Crashes if AI answers directly!

# ✅ RIGHT — always check:
if message.tool_calls:
    # handle tool call
else:
    # AI answered directly, just print message.content
```

## 🏗️ Mini Project: Multi-Tool Assistant

Build an assistant with 3 tools:

```python
"""
🛠️ Multi-Tool Assistant
Tools: weather, calculator, knowledge base
"""
import json
from dotenv import load_dotenv
from openai import OpenAI

load_dotenv()
client = OpenAI()

# ─── YOUR FUNCTIONS ─────────────────────────────────────────

def get_weather(city):
    data = {"mumbai": "32°C sunny", "delhi": "38°C hot", "bangalore": "24°C pleasant"}
    return data.get(city.lower(), f"No data for {city}")

def calculate(expression):
    try:
        return str(eval(expression))
    except:
        return "Can't calculate that"

def search_notes(query):
    notes = {
        "meeting": "Team standup at 10am Monday",
        "deadline": "Project due Friday 5pm",
        "idea": "Build an AI agent for email sorting",
    }
    for key, value in notes.items():
        if query.lower() in key or query.lower() in value.lower():
            return value
    return f"No notes found about '{query}'"

# ─── TOOL SCHEMAS ───────────────────────────────────────────

tools = [
    {
        "type": "function",
        "function": {
            "name": "get_weather",
            "description": "Get weather for an Indian city",
            "parameters": {
                "type": "object",
                "properties": {"city": {"type": "string", "description": "City name"}},
                "required": ["city"]
            }
        }
    },
    {
        "type": "function",
        "function": {
            "name": "calculate",
            "description": "Evaluate a math expression",
            "parameters": {
                "type": "object",
                "properties": {"expression": {"type": "string", "description": "e.g. '42*17'"}},
                "required": ["expression"]
            }
        }
    },
    {
        "type": "function",
        "function": {
            "name": "search_notes",
            "description": "Search personal notes and reminders",
            "parameters": {
                "type": "object",
                "properties": {"query": {"type": "string", "description": "What to search for"}},
                "required": ["query"]
            }
        }
    }
]

# Map function names to actual functions:
available_functions = {
    "get_weather": get_weather,
    "calculate": calculate,
    "search_notes": search_notes,
}

# ─── THE INTERACTION ────────────────────────────────────────

def ask_assistant(question):
    """Ask the assistant a question. It may use tools."""
    messages = [
        {"role": "system", "content": "You are a helpful assistant with access to tools. Use them when needed."},
        {"role": "user", "content": question}
    ]
    
    # First call: AI decides what to do
    response = client.chat.completions.create(
        model="gpt-4o-mini", messages=messages, tools=tools
    )
    
    message = response.choices[0].message
    
    # If AI wants to use a tool:
    if message.tool_calls:
        messages.append(message)
        
        for tool_call in message.tool_calls:
            name = tool_call.function.name
            args = json.loads(tool_call.function.arguments)
            
            print(f"  🔧 Using tool: {name}({args})")
            
            # Execute the function
            func = available_functions[name]
            result = func(**args)
            
            messages.append({
                "role": "tool",
                "tool_call_id": tool_call.id,
                "content": str(result)
            })
        
        # Second call: AI generates final answer
        final = client.chat.completions.create(
            model="gpt-4o-mini", messages=messages, tools=tools
        )
        return final.choices[0].message.content
    else:
        return message.content

# ─── TEST IT ────────────────────────────────────────────────

questions = [
    "What's the weather in Bangalore?",
    "What is 15% of 2400?",
    "When is my project deadline?",
    "Tell me a fun fact about AI",  # No tool needed!
]

for q in questions:
    print(f"\n👤 {q}")
    answer = ask_assistant(q)
    print(f"🤖 {answer}")
```

## 🧠 Connect to the Agent Loop (Lesson 1.4)

Remember this?

```
THINK → ACT → OBSERVE → repeat
```

Function calling IS this loop:

| Agent Loop | Function Calling |
|-----------|-----------------|
| **THINK** | LLM reads question + tools, decides what to call |
| **ACT** | Your code executes the function |
| **OBSERVE** | Result sent back to LLM |
| **Repeat** | LLM may call another tool, or give final answer |

In Lesson 3.2, you'll wrap this in a `while` loop → **a real agent!**

## ✅ Knowledge Check

1. Does the LLM execute your function? → **No! It just REQUESTS it. Your code executes.**
2. What format describes tools? → **JSON Schema (name, description, parameters)**
3. What role sends results back? → **`"role": "tool"` with `tool_call_id`**
4. How many API calls for one tool use? → **Two (request + final answer)**
5. What if the AI answers without tools? → **Check `if message.tool_calls:` first**
