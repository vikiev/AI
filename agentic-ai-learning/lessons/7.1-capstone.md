## The 6 Tools

| Tool | What it does | API needed? |
|------|-------------|-------------|
| `get_time` | Current date/time | ❌ Python datetime |
| `calculate` | Safe math evaluation | ❌ Python eval |
| `search_wikipedia` | Look up any topic | ❌ Free, no key |
| `get_weather` | Weather for any city | ❌ wttr.in (free) |
| `save_note` | Persist notes to disk | ❌ Local JSON file |
| `recall_notes` | Read saved notes | ❌ Local JSON file |

**Zero API keys needed beyond OpenAI!** Everything else is free.

### Key patterns in the code:

**1. Every tool returns a string (even errors):**
```python
def get_weather(city: str) -> str:
    try:
        # ... API call
        return f"Weather in {city}: ..."
    except Exception as e:
        return f"Weather error: {str(e)}"  # ← Agent reads this, adapts
```

**2. Budget class prevents runaway costs:**
```python
class Budget:
    def track(self, usage):
        self.tokens_used += usage.total_tokens
    def exceeded(self):
        return self.tokens_used > self.max_tokens
```

**3. Retry with exponential backoff:**
```python
for attempt in range(3):
    try:
        return client.chat.completions.create(...)
    except RateLimitError:
        time.sleep(2 ** attempt)  # 1s → 2s → 4s
```

**4. Safe calculator (no arbitrary code execution):**
```python
allowed_chars = set("0123456789+-*/.() ")
if not all(c in allowed_chars for c in expression):
    return "Error: Only basic math allowed."
result = eval(expression, {"__builtins__": {}})  # ← Empty builtins = safe
```

**5. Persistent notes (survives restarts):**
```python
NOTES_FILE = Path(__file__).parent / "notes.json"
# Read → append → write back
```
