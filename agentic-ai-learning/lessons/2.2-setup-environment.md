## Step 1: Verify Python is Installed

Open your terminal (Command Prompt, PowerShell, or VS Code terminal):

```bash
python --version
```

**You want to see:** `Python 3.10` or higher (3.11, 3.12, 3.13 all fine)

### 🚨 Troubleshooting

| Problem | Fix |
|---------|-----|
| `'python' is not recognized` | Install from [python.org](https://python.org) → check "Add to PATH" during install |
| Shows Python 2.7 | You need Python 3! Uninstall old version, install new |
| Shows 3.8 or 3.9 | Works, but 3.11+ is better. Upgrade if easy. |

Also check pip (Python's package installer):
```bash
pip --version
```
Should show `pip 23+`. If not: `python -m pip install --upgrade pip`

## Step 2: Install the OpenAI Library

```bash
pip install openai python-dotenv
```

### What just happened?

| Package | What It Does | Why You Need It |
|---------|-------------|-----------------|
| `openai` | Official Python library for OpenAI's API | Lets you call GPT-4o, DALL-E, Whisper from Python |
| `python-dotenv` | Loads variables from a `.env` file | Keeps your API key out of your code (security!) |

### Verify it worked:

```bash
python -c "import openai; print(openai.__version__)"
```

Should print something like `1.99.0` (any 1.x is fine).

### 🚨 Troubleshooting

| Problem | Fix |
|---------|-----|
| `pip: command not found` | Try `python -m pip install openai python-dotenv` |
| Permission error | Add `--user` flag: `pip install --user openai` |
| Multiple Python versions | Use `python3 -m pip install openai` or `py -m pip install openai` (Windows) |

## Step 3: Get Your API Key

### What is an API key?

Think of it as a **password that lets your code use OpenAI's AI models**. Every time your code calls GPT-4o, OpenAI checks your key and charges your account a tiny amount.

### How to get one:

1. Go to [platform.openai.com](https://platform.openai.com)
2. Sign up / Log in
3. Go to **API Keys** section (left sidebar → your name → API Keys)
4. Click **"Create new secret key"**
5. Copy it immediately (starts with `sk-...`)

> ⚠️ **You only see it ONCE.** Copy it right away. If you lose it, create a new one.

### 💰 Cost awareness

| Model | Input (per 1M tokens) | Output (per 1M tokens) |
|-------|----------------------|------------------------|
| gpt-4o | $2.50 | $10.00 |
| gpt-4o-mini | $0.15 | $0.60 |

**For learning:** Use `gpt-4o-mini` — it's 20x cheaper and still very capable. A typical lesson costs < $0.01.

You can set spending limits in your OpenAI dashboard → Settings → Limits.

## Step 4: Create the `.env` File

### WHY not just put the key in your code?

```python
# ❌ NEVER DO THIS:
client = OpenAI(api_key="sk-proj-abc123...")

# Why it's bad:
# 1. You'll accidentally push it to GitHub → anyone can use your key
# 2. You'll share a screenshot → key exposed
# 3. You'll copy-paste code → key goes everywhere
```

### The solution: `.env` file

A `.env` file is a simple text file that stores secrets **outside** your code.

**Create a file called `.env`** in your project root:

```env
OPENAI_API_KEY=sk-proj-your-actual-key-here
```

**Rules:**
- No spaces around `=`
- No quotes around the value
- One variable per line
- File name is literally `.env` (with the dot at the start)

### 🚨 Protect it from Git

Create/verify your `.gitignore` file has:

```gitignore
# Never commit secrets
.env

# Python stuff
__pycache__/
*.pyc
.venv/
```

**Test it:** Run `git status` — you should NOT see `.env` listed.

---

## Step 5: How Python Reads the Key

Here's the magic — 3 lines of Python:

```python
from dotenv import load_dotenv
import os

load_dotenv()  # ← Reads .env file, puts values into "environment"

# Now you can access it:
my_key = os.getenv("OPENAI_API_KEY")
print(f"Key starts with: {my_key[:8]}...")  # sk-proj... (don't print the whole thing!)
```

### But wait — it gets even easier!

The OpenAI library **automatically** looks for `OPENAI_API_KEY` in your environment. So you don't even need to pass it:

```python
from dotenv import load_dotenv
from openai import OpenAI

load_dotenv()  # Load .env into environment

client = OpenAI()  # ← Automatically finds OPENAI_API_KEY! No need to pass it.
```

That's it. That's the whole setup.

## Step 6: The "It Works!" Test

Create a file called `test_setup.py`:

```python
"""
Quick test: Is everything working?
Run: python test_setup.py
"""
from dotenv import load_dotenv
from openai import OpenAI

# Step 1: Load environment variables
load_dotenv()

# Step 2: Create client
client = OpenAI()

# Step 3: Make a tiny API call
print("🔌 Testing connection to OpenAI...")

response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Say 'Setup works!' in exactly 2 words."}],
    max_tokens=10
)

# Step 4: Print result
answer = response.choices[0].message.content
print(f"✅ AI responded: {answer}")
print(f"📊 Tokens used: {response.usage.total_tokens}")
print("\n🎉 You're ready to build agents!")
```

Run it:
```bash
python test_setup.py
```

**Expected output:**
```
🔌 Testing connection to OpenAI...
✅ AI responded: Setup works!
📊 Tokens used: 24

🎉 You're ready to build agents!
```

### 🚨 Troubleshooting

| Error | Cause | Fix |
|-------|-------|-----|
| `ModuleNotFoundError: No module named 'openai'` | Package not installed | `pip install openai python-dotenv` |
| `ModuleNotFoundError: No module named 'dotenv'` | python-dotenv not installed | `pip install python-dotenv` |
| `AuthenticationError` | Wrong/missing API key | Check `.env` file exists, key is correct, no extra spaces |
| `RateLimitError` | No credits / limit hit | Add credits at platform.openai.com → Billing |
| `ConnectionError` | No internet / firewall | Check internet, try disabling VPN |
| `openai.NotFoundError` | Wrong model name | Use `gpt-4o-mini` (not `gpt-4-mini`) |

## 🧠 Understanding What Just Happened

### The full flow (what happens when you run code):

```
1. python test_setup.py
       │
       ▼
2. load_dotenv() reads .env file
       │
       ▼
3. OPENAI_API_KEY is now in Python's "environment"
       │
       ▼
4. OpenAI() checks environment for the key
       │
       ▼
5. client.chat.completions.create(...) sends:
   ┌──────────────────────────────────────┐
   │ POST https://api.openai.com/v1/chat  │
   │ Headers:                              │
   │   Authorization: Bearer sk-proj-...   │
   │ Body:                                 │
   │   {"model": "gpt-4o-mini",           │
   │    "messages": [...]}                 │
   └──────────────────────────────────────┘
       │
       ▼
6. OpenAI servers process with GPT-4o-mini
       │
       ▼
7. Response comes back as a Python object
       │
       ▼
8. You read: response.choices[0].message.content
```

### Key insight:

> You're not running AI on your computer. You're sending text to OpenAI's servers, they run the AI, and send back the response. Your API key is your "ticket" to use their computers.
