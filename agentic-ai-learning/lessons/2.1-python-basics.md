## Level 2: Functions = Mini Machines (10 minutes)

### What's a function?

A function is a **reusable recipe**: put stuff in → get stuff out.

```python
def make_tea(flavor):
    """Given a flavor, returns a tea order."""
    return f"One {flavor} tea, coming right up! ☕"

# Use it (we say "call" the function):
order = make_tea("ginger")
print(order)  # One ginger tea, coming right up! ☕

order2 = make_tea("masala")
print(order2)  # One masala tea, coming right up! ☕
```

### The anatomy:

```
def  make_tea (flavor):        ← name + input (parameter)
     ────────  ───────
     │         └── what goes IN
     └── the name (verb + noun works well)
    
    return f"One {flavor} tea"  ← what comes OUT
    ──────
    └── sends the result back
```

### 🤖 Agent Connection: Tools ARE Functions!

Remember from Module 1 — agents use "tools." In code, **tools are just functions**:

```python
# This IS a tool that an AI agent will use:
def get_weather(city):
    """Get the current weather for a city."""
    # (pretend we called a weather API)
    return f"It's 28°C and sunny in {city} ☀️"

# The agent "decides" to call this:
result = get_weather("Mumbai")
print(result)  # It's 28°C and sunny in Mumbai ☀️
```

The agent doesn't write code — it just **calls your function** with the right arguments.

### Multiple inputs, multiple outputs

```python
def calculate_cost(tokens, price_per_million):
    """Calculate API cost."""
    cost = (tokens / 1_000_000) * price_per_million
    return cost

my_bill = calculate_cost(tokens=50_000, price_per_million=2.50)
print(f"Cost: ${my_bill:.4f}")  # Cost: $0.1250
```

### 🧪 TRY IT: Write a tool

## Level 3: Dictionaries = The AI Data Structure (10 minutes)

### Why dictionaries are EVERYTHING in AI

If you remember ONE thing from this lesson:

> **Every AI message is a dictionary. Every API response is a dictionary. Every tool call is a dictionary.**

### What's a dictionary?

A dictionary stores **key → value** pairs. Like a real dictionary: word → definition.

```python
# A dictionary (dict for short):
user = {
    "name": "Vikiev",       # key: "name" → value: "Vikiev"
    "city": "Mumbai",       # key: "city" → value: "Mumbai"
    "age": 30,              # keys are strings, values can be anything
    "is_learning": True
}

# Access values by key:
print(user["name"])    # Vikiev
print(user["city"])    # Mumbai

# Add new stuff:
user["favorite_tea"] = "masala chai"

# Change stuff:
user["age"] = 31  # happy birthday!
```

### 🤖 THE most important dictionary you'll ever see:

```python
# This is how you talk to an AI. This IS the message format:
message = {
    "role": "user",
    "content": "What's the weather in Mumbai?"
}
```

That's it. That's how you send a message to GPT. A dictionary with two keys.

### The three roles:

```python
system_msg = {"role": "system", "content": "You are a weather assistant."}
user_msg = {"role": "user", "content": "Will it rain today?"}
assistant_msg = {"role": "assistant", "content": "Let me check... No rain expected!"}
```

### 🧪 TRY IT: Build a conversation

## Level 5: If/Else = Making Decisions (5 minutes)

### Your code needs to make choices

```python
temperature = 35

if temperature > 30:
    print("Hot! Stay hydrated ☀️")
elif temperature > 20:
    print("Nice weather 🌤️")
else:
    print("Cold! Wear a jacket 🧥")
```

### 🤖 Agent Connection: The most important `if` in agents

```python
response = {"has_tool_calls": True, "content": None}

if response["has_tool_calls"]:
    print("🔧 Agent wants to use a tool → execute it, keep looping")
else:
    print("✅ Agent has a final answer → return it, stop looping")
```

This single `if/else` is the **heart of the agent loop** (from Lesson 1.4)!

### 🧪 TRY IT:

```python
# Simulate an agent's decision:
def agent_decide(user_message):
    """Decide what the agent should do."""
    
    if "weather" in user_message.lower():

    else:

# Test it:
action, tool = agent_decide("What's the weather in Delhi?")
print(f"Action: {action}, Tool: {tool}")

action, tool = agent_decide("Tell me a joke")
```

## Level 6: Loops = The Agent Engine (5 minutes)

### for loops: repeat over items

```python
# Process each message in a conversation:
messages = ["Hi!", "How are you?", "What's an agent?"]

for msg in messages:
    print(f"Processing: {msg}")
```

### while loops: repeat until done

```python
# This IS the agent loop pattern:
steps = 0
max_steps = 5
task_done = False

while not task_done and steps < max_steps:
    steps += 1
    print(f"🔄 Step {steps}: Agent is thinking...")
    
    # Pretend the agent finishes on step 3:
    if steps == 3:
        task_done = True
        print("✅ Task complete!")

print(f"Finished in {steps} steps")
```

### 🤖 This is literally how agents work:

```python
# Pseudo-code for a real agent:
messages = [system_prompt, user_question]

for iteration in range(10):  # max 10 steps (safety!)
    response = call_llm(messages)  # THINK
    
    if response.has_tools:         # ACT
        result = execute_tool(response.tool)
        messages.append(result)    # OBSERVE
        # → loop continues
    else:
        return response.content    # DONE! Exit loop
```

### 🧪 TRY IT:

```python
# Simulate an agent loop:
def simulate_agent(goal, max_steps=5):
    """Pretend to be an agent working on a goal."""
    print(f"🎯 Goal: {goal}")
    
    for step in range(1, max_steps + 1):
        print(f"  Step {step}: Thinking...")
        
        # Fake: agent "figures it out" on random step
        if step == 3:  # (pretend this is when it's done)
            print(f"  ✅ Done! Answer found in {step} steps.")
            return "The answer is 42!"
    
    return "Couldn't figure it out 😅"

result = simulate_agent("What is the meaning of life?")
print(f"Final: {result}")
```

## Level 7: Imports + Error Handling (5 minutes)

### Importing libraries

```python
import os                    # operating system (files, env vars)
import json                  # work with JSON (API responses)
from openai import OpenAI    # the OpenAI library (next lesson!)
```

Think of imports as: "Hey Python, I need someone else's code for this."

### Error handling (try/except)

Things go wrong. APIs fail. Here's how you handle it gracefully:

```python
def call_api(url):
    """Pretend to call an API that might fail."""
    try:
        # Code that MIGHT fail:
        result = "success!"  # (pretend this is an API call)
        return result
        
    except ConnectionError:
        return "Error: No internet connection"
    except TimeoutError:
        return "Error: API took too long"
    except Exception as e:
        return f"Error: Something went wrong ({e})"

response = call_api("https://api.openai.com")
print(response)
```

### 🤖 Agent Connection:

```python
# In a real agent, you wrap tool calls in try/except:
def execute_tool_safely(tool_name, arguments):
    """Execute a tool, but don't crash if it fails."""
    try:
        result = tools[tool_name](**arguments)
        return {"success": True, "result": result}
    except Exception as e:
        return {"success": False, "error": str(e)}
        # The agent sees the error and can try something else!
```

## 🎮 Level 8: Put It All Together — Mini Project

### Build a "Fake Agent" (no API needed!)

This uses EVERYTHING you just learned:

```python
"""
🤖 FAKE AGENT — Uses all 7 concepts!
Run this and see an "agent" work.
"""

# ─── CONCEPT: Variables ───────────────────────────
agent_name = "MiniBot"
max_steps = 5

# ─── CONCEPT: Dictionaries ────────────────────────
# Fake knowledge base (the agent's "brain")
knowledge = {
    "capital of india": "New Delhi",
    "capital of france": "Paris",
    "largest planet": "Jupiter",
    "best programming language for ai": "Python, obviously! 🐍",
}

# ─── CONCEPT: Functions (= Tools!) ────────────────
def search_knowledge(query):
    """Tool: Search the knowledge base."""
    answer = knowledge.get(query.lower())
    if answer:
        return f"Found it: {answer}"
    return f"No results for '{query}'"

def calculate(expression):
    """Tool: Do math."""
    try:
        result = eval(expression)  # (unsafe in production, fine for learning!)
        return f"{expression} = {result}"
    except:
        return f"Can't calculate: {expression}"

# ─── CONCEPT: Lists ───────────────────────────────
conversation = []  # Agent's memory

# ─── CONCEPT: If/Else + Loops ─────────────────────
def agent_respond(user_message):
    """The agent decides what to do."""
    
    # Add user message to memory
    conversation.append({"role": "user", "content": user_message})
    
    # Decide: which tool to use?
    if any(word in user_message.lower() for word in ["capital", "planet", "language"]):
        # Use knowledge tool
        tool_result = search_knowledge(user_message)
        response = f"🔍 I searched my knowledge base. {tool_result}"
        
    elif any(char in user_message for char in "0123456789+-*/"):
        # Use calculator tool
        # Extract just the math part (simple approach)
        response = f"🧮 Let me calculate... {calculate(user_message)}"
        
    elif "bye" in user_message.lower():
        response = "👋 Goodbye! It was fun being a fake agent!"
        
    else:
        response = f"🤔 I'm a simple agent. I can answer facts or do math. Try asking about capitals or give me a calculation!"
    
    # Add agent response to memory
    conversation.append({"role": "assistant", "content": response})
    return response

# ─── CONCEPT: Imports (not needed here, but in real agents!) ──

# ─── RUN THE AGENT ────────────────────────────────
print(f"🤖 {agent_name} is online! (type 'bye' to quit)\n")

# Simulated conversation:
test_messages = [
    "What is the capital of India?",
    "Calculate 42 * 17",
    "What is the largest planet?",
    "Tell me a joke",
    "bye"
]

for msg in test_messages:
    print(f"👤 You: {msg}")
    reply = agent_respond(msg)
    print(f"🤖 {agent_name}: {reply}")
    print()

# Show the conversation memory:
print(f"📝 Conversation had {len(conversation)} messages total")
```

**Run it and watch your "agent" work!** It's fake (no real AI), but the STRUCTURE is exactly how real agents work.

```python
client = OpenAI()

def agent_loop(question, tools):

    for step in range(10):
        response = client.chat.completions.create(
            model="gpt-4o", messages=messages, tools=tools
        )
        
        if response.choices[0].message.tool_calls:
            # Execute tool, add result to messages
            ...
        else:
            return response.choices[0].message.content
```
